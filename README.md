# TaskFlow

Совместный менеджер задач для команды.

## Возможности
- вход по имени и Telegram нику;
- доступ только для ников, добавленных главным администратором;
- главный администратор: Вася — @SUBBOY1;
- создание тематических папок;
- создание задач с описанием и приоритетом;
- отметка выполнения задач любым пользователем;
- видно, кто выполнил задачу;
- управление списком допущенных пользователей.

## Запуск
Сайт статический и готов для GitHub Pages.

В GitHub: **Settings → Pages → Deploy from a branch → main / root**.

> Данные хранятся локально в браузере через localStorage. Для общего синхронизируемого рабочего пространства потребуется backend/БД (например Firebase или Supabase).
